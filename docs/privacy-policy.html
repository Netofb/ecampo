Política de Privacidade do eCampo

Última atualização: 21 de agosto de 2026

O eCampo é um aplicativo de gestão de operações de campo, desenvolvido e responsável por Fabio Barros Lima. Esta política explica quais dados são tratados e para quais finalidades.

Dados coletados

  • Dados de cadastro e acesso: informações necessárias para identificar o usuário, incluindo CPF e dados de autenticação.
  • Localização: posição do dispositivo quando o usuário concede a permissão e utiliza recursos de GPS ou mapa.
  • Dados de campo: informações registradas pelo usuário sobre localidades, quarteirões, faces, imóveis, pontos, produção, fotos e observações.

Como os dados são usados

Os dados são usados para autenticar o acesso, registrar e consultar informações de campo, exibir mapas, associar posições aos registros e sincronizar as informações entre o aplicativo e o serviço do eCampo.

Compartilhamento

Não vendemos nem compartilhamos os dados pessoais e dados de campo com terceiros para fins comerciais. O acesso é restrito às finalidades do eCampo e às pessoas autorizadas pelo responsável pela operação.

Armazenamento e segurança

Adotamos medidas técnicas e administrativas razoáveis para proteger os dados contra acesso não autorizado, perda ou alteração. Nenhum sistema é completamente livre de riscos.
